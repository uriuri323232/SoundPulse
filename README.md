# SoundPulse

נגן הקלטות לריכוז ולהליכה: גלי קול, פרקים אוטומטיים לפי שתיקות, סימניות ודגלים, מצב הליכה במחוות,
מעבד דיבור, טיימר שינה, וניהול אחסון (כפולים, ישנים, זבל, כיווץ).

## בנייה
`gradle assembleDebug` (או GitHub Actions: `.github/workflows/build.yml`).
Gradle 8.9 · AGP 8.7.3 · Kotlin 2.0.20 · compileSdk 35.
