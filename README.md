# פוקוס אודיו

נגן שמע לאנדרואיד (8 ומעלה, כולל 13) שעובד כולו ללא אינטרנט. Kotlin, Jetpack Compose ו-Media3.

## מה יש בו
- **נגן עם גלי קול:** מפת גלים אינטראקטיבית (הקשה או גרירה מזיזה את ההשמעה), חלוקה אוטומטית לפרקים בנקודות שקט של 2 שניות ומעלה, סימניות עם הערה ודגלים.
- **מעבד דיבור בזמן ניגון:** אקולייזר שמבליט 300 עד 4000 הרץ ומדכא רעמים וסיסוב, מדחס שמאזן קטעים חלשים וחזקים, ושער רעש שמנמיך רעשי רקע שקטים. זה סינון רעשים בסיסי ולא ניקוי מלא כמו במודלים מתקדמים. דורש אנדרואיד 9 ומעלה למדחס.
- **מצב הליכה:** המסך כולו לוח מחוות. הקשה: ניגון והשהיה. החלקה ימינה או שמאלה: 30 שניות קדימה או אחורה. החלקה למעלה: סימנייה. החלקה למטה: הפרק הבא. לחיצה כפולה מקריאה בסבב את שם הקובץ, הזמן שנותר ותוכן הסימנייה האחרונה.
- **ניהול אחסון:** סריקה לאיתור קבצים כפולים (לפי תוכן), הקלטות מעל 90 יום וקבצי זבל זמניים, מחיקה רק אחרי אישור. כיווץ אוטומטי של קבצים שהושמעו במלואם ל-AAC בקצב 48 kbps. הקובץ המקורי נמחק רק אם התוצאה קטנה ממנו משמעותית.

## איך משתמשים
בלשונית "ספרייה" בוחרים תיקייה (אפשר גם בכרטיס SD). האפליקציה קוראת ומנהלת קבצים רק בתיקייה הזאת.

## קבלת APK
ב-GitHub נכנסים ל-Actions, מריצים את Build APK, ומורידים את `focus-audio-apk` מסעיף Artifacts.

## מגבלות ידועות
- הקראה קולית בעברית דורשת קול עברי מותקן במכשיר (הגדרות, ניהול כללי, טקסט לדיבור).
- ניתוח ההקלטה לגלים ולפרקים רץ בכל פתיחה מחדש וייקח זמן בהקלטות ארוכות מאוד.
- הקוד לא נבנה ולא נבדק על מכשיר בזמן היצירה.
