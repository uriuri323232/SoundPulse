# SoundPulse

נגן הקלטות ושיעורים לאנדרואיד (8 ומעלה), עובד כולו ללא אינטרנט. Kotlin, Jetpack Compose ו-Media3.

## מה יש בו
- **נגן עם גלי קול:** הקשה או גרירה מזיזה את ההשמעה, חלוקה אוטומטית לפרקים בשקטים, סימניות עם הערה ודגלים (אפשר לערוך ולמחוק, עם ביטול).
- **המשך מאיפה שעצרת:** האפליקציה זוכרת את המקום בכל הקלטה וחוזרת 3 שניות אחורה כדי להיכנס לעניין. בספרייה רואים "נעצר ב-..." ופס התקדמות. בפתיחה מחדש ההקלטה האחרונה נטענת בנקודה שבה עצרת.
- **טאב סימונים:** כל הדגלים וההערות מכל ההקלטות במקום אחד, חיפוש, סינון לפי דגלים או סימניות, קפיצה ישירה לנקודה בהקלטה ושיתוף כטקסט.
- **ספרייה חכמה:** חיפוש, סינון "שלא הושמעו" ו"באמצע", מיון (שם / חדשות / ישנות / גדולות), משך ופס התקדמות לכל הקלטה, תפריט לסימון הושמע ואיפוס מקום, וכפתור רענון. נגן מיני עם כפתורי קפיצה בתחתית המסך בכל הלשוניות.
- **טיימר שינה:** 5 עד 90 דקות, עם הנמכת קול הדרגתית בחצי הדקה האחרונה.
- **המשך אוטומטי:** בסוף הקלטה עובר להקלטה הבאה.
- **מהירות:** 0.5x עד 3x, עם כוונון עדין בקפיצות של 0.05. נשמרת בין הפעלות.
- **אורך קפיצה:** 5, 10, 15, 30, 45 או 60 שניות (בהגדרות), בנגן, בנגן המיני ובמצב הליכה.
- **מעבד דיבור** ודילוג על שקטים.
- **מצב הליכה (מחוות):** הקשה: ניגון והשהיה. החלקה ימינה: 30 שניות קדימה, שמאלה: אחורה (אפשר להפוך כיוון בכפתור). החלקה למעלה: סימנייה. החלקה למטה: הפרק הבא. לחיצה ארוכה: דגל. הקשה כפולה: הקראה. רטט והבהוב לכל פעולה, אפשרות לקול שמאשר כל פעולה, והמסך נשאר דלוק.
- **ניהול אחסון:** איתור כפולים, הקלטות ישנות וקבצי זבל, וכיווץ קבצים שהושמעו ל-AAC.

## קבלת APK
ב-GitHub נכנסים ל-Actions, מריצים Build APK, ומורידים את `focus-audio-apk` מסעיף Artifacts.

## מגבלות ידועות
- הקראה קולית בעברית דורשת קול עברי מותקן במכשיר.
- ניתוח ההקלטה לגלים רץ בפעם הראשונה בלבד ונשמר.
